# 📚 CRUD Application - Spring Boot

This is a **CRUD (Create, Read, Update, Delete) application** built with **Spring Boot**.  
It provides RESTful APIs to manage book records with a focus on **scalability, efficiency, and maintainability**.  

---

## 🚀 Features
- Add new book records 📖  
- Retrieve book details 🔍  
- Update existing records ✏️  
- Delete records ❌  
- REST API architecture 🌐  
- Exception handling & validation ⚡  
- Connected to a relational database (MySQL/PostgreSQL)  

---

## 🛠️ Tech Stack
- **Backend:** Spring Boot (REST APIs)  
- **Database:** MySQL / PostgreSQL  
- **Build Tool:** Maven  
- **Version Control:** Git & GitHub  
- **IDE:** IntelliJ IDEA / Eclipse
